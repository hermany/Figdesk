# Base prompt

What the AI is asked to build in this project, whatever the mode. A smart section's mode document says
how to build one kind of output; this file says what the project is.

## Project

- **name**: (not set)
- **what it is**: (not set: one or two lines, who it is for and what it does)
- **language of the text**: the language of the texts in the design

## Rules for every run

- The design in the smart section is the source: build what it shows, with its own words, colours and
  spacing.
- Frames of the same size inside the section that share their structure (same layers, same layout) are
  states of ONE screen, not separate pages. Build one screen and change the elements that differ (a
  state, a variant, a toggle), and keep the rest as it is. Make separate screens only when the frames
  are really different screens.
- Write everything inside this work folder.
